# AI Animator Studio

وب‌اپلیکیشن فارسی و راست‌به‌چپ برای طراحی و پیش‌تولید انیمیشن دوبعدی.

**نسخه وب:** https://mslm8.github.io/index.html/

## امکانات موجود

- دریافت ایده یا فیلمنامه و ساختاردهی صحنه‌ها
- پیش‌نمایش حرکت و ضبط خروجی WebM در مرورگر
- ویرایش صحنه‌ها، فهرست نماها و خط زمانی تولید
- کتابخانه شخصیت‌ها و مکان‌ها، راهنمای پیوستگی و چک‌لیست کنترل کیفیت
- ورود و خروج پروژه به JSON و خروجی فهرست نماها به CSV
- کارگردان خودکار قواعدمحور برای پیشنهاد حرکت، احساس، دوربین و تداوم
- ویرایشگر ریگ ساده و ذخیره پروفایل‌های محلی
- پنل عیب‌یابی مرورگر و سرویس‌ها، گزارش خطا و تلاش مجدد درخواست‌های امن
- اتصال اختیاری به Supabase، Cloudflare Workers AI و PostHog

## معماری سرویس‌ها

| بخش | وظیفه |
| --- | --- |
| GitHub Pages | میزبانی نسخه وب |
| Supabase Auth | احراز هویت کاربر |
| Supabase Edge Function: `fal-gateway` | دروازه امن درخواست‌های تصویر و سرویس‌های متصل |
| Supabase Edge Function: `studio-manager` | بررسی سلامت و تحلیل گزارش عیب‌یابی |
| Cloudflare Worker | درخواست تولید تصویر با Workers AI |
| PostHog | تحلیل رویدادها و ثبت خطا؛ تا زمان تنظیم Secret و Variable در GitHub غیرفعال می‌ماند |

## انتشار

هر commit روی شاخه `main`، گردش‌کار GitHub Actions را اجرا می‌کند. ابتدا اعتبارسنجی HTML و JavaScript، تست‌های رگرسیون و بررسی نوع توابع Supabase انجام می‌شود؛ سپس نسخه وب در GitHub Pages منتشر می‌شود.

وضعیت آخرین انتشار را در [GitHub Actions](https://github.com/mslm8/index.html/actions) ببین.

## تنظیمات محرمانه

هیچ کلید یا توکنی را در HTML، فایل‌های JavaScript یا این مخزن قرار نده.

### Supabase Edge Functions

تنظیمات سرویس‌ها باید فقط در Secrets مربوط به Supabase ثبت شوند. برای مسیرهای فعلی، نام‌های موردنیاز شامل موارد زیر است:

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`
- `FAL_KEY` (اختیاری؛ وابسته به سرویس پولی و اعتبار حساب)
- `OPENAI_API_KEY` و `OPENAI_MANAGER_MODEL` (اختیاری؛ برای تحلیل هوشمند مدیر برنامه)

وجود Secret به‌تنهایی مجوز یا موفقیت سرویس را ثابت نمی‌کند؛ هر سرویس باید با درخواست واقعی بررسی شود.

### PostHog

گردش‌کار انتشار برای ساخت تنظیمات مرورگر از این مقادیر استفاده می‌کند:

- GitHub Actions Secret: `POSTHOG_PROJECT_TOKEN`
- GitHub Actions Variable: `POSTHOG_API_HOST` با مقدار `https://eu.i.posthog.com`

تا وقتی هر دو مقدار تنظیم نشده‌اند، جمع‌آوری رویدادهای PostHog غیرفعال است. توکن را در چت یا کد منبع قرار نده.

## محدودیت‌های شناخته‌شده نسخه فعلی

- تولید تصویر به مجوز واقعی مدل و سهمیه حساب Cloudflare وابسته است؛ نمایش مدل در فهرست به معنی موفقیت inference نیست.
- AI Horde عمداً به‌عنوان fallback استفاده نمی‌شود تا خطای سهمیه ناشناس تکرار نشود.
- کارگردان خودکار فعلی قواعدمحور است و جایگزین مدل مولد فیلمنامه یا کارگردانی هوشمند نیست.
- پیش‌نمایش و ضبط WebM در مرورگر انجام می‌شود؛ خروجی MP4 نهایی و lip-sync کامل در خط تولید وب تضمین نشده‌اند.
- ریگ‌گذاری فعلی ساده و دستی است؛ جداسازی خودکار اندام‌ها و ساخت ریگ حرفه‌ای وجود ندارد.
- گردش‌کار Tahoma2D در GitHub Actions برای آزمون موقت نصب و رندر است؛ یک ماشین ابری دائمی و متصل به برنامه ایجاد نمی‌کند.
- فایل‌ها و پروفایل‌های محلی در فضای مرورگر ذخیره می‌شوند و به‌صورت خودکار بین دستگاه‌ها همگام‌سازی نمی‌شوند.

## اجرای محلی

برای پیش‌نمایش نسخه وب، مخزن را دریافت و فایل `index.html` را از طریق یک وب‌سرور محلی باز کن. برای آزمایش احراز هویت و Edge Functionها، تنظیمات Supabase معتبر و نشست کاربر لازم است.

## امنیت و حریم خصوصی

- کلیدهای سرویس فقط در Secrets سمت سرور نگهداری شوند.
- گزارش عیب‌یابی باید قبل از ارسال از اطلاعات حساس پاک‌سازی شود.
- برای endpointهای عمومی، CORS به‌تنهایی جایگزین احراز هویت، محدودیت نرخ و اعتبارسنجی ورودی نیست.
- قبل از فعال‌کردن ثبت رویدادها یا ضبط نشست، تنظیمات رضایت و حریم خصوصی را بررسی کن.
